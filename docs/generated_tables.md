# Generated Tables

This document describes all derived tables produced by the processing pipeline.
Most files are generated by running `processing/01_*.py` through `07_*.py` in order; the "Generated by" column gives the exact source of each.
None of these files are committed to the repository. Most can be regenerated from the raw inputs; the ones marked "Not generated by any script" cannot.

See [pipeline_overview.md](pipeline_overview.md) for run order and per-script I/O details,
and [data_availability.md](data_availability.md) for how to obtain the required raw inputs.

---

## Primary derived tables (`data/derived/`)

These are the main tables consumed by figure scripts.

### `synapses_783_article_princeton.ftr`

Generated by: `processing/04_build_master_synapse_table.py`

Per-synapse table. This is the central analysis table — almost all figure scripts use it.

| Column | Description |
|--------|-------------|
| `synapse_id` | Row number of the synapse in the input Codex CSV, not a Codex ID; it only matches that exact file |
| `pre` | Pre-synaptic neuron root ID |
| `post` | Post-synaptic neuron root ID |
| `comp` | Pre compartment followed by post compartment (`A`, `D` or `L` each), so nine values are possible: `AA` (axo-axonic), `AD` (axo-dendritic), `DA` (dendro-axonic), `DD` (dendro-dendritic), and five that involve a linker (`AL`, `LA`, `DL`, `LD`, `LL`). Filter to `AA`/`AD`/`DA`/`DD` explicitly before analysing synapse types |
| `SI_pre` | Segregation Index of the pre-synaptic neuron (the older SI in the authors' table the figures were made from, which is not included; see `SI_updated.ftr` below) |
| `SI_post` | Segregation Index of the post-synaptic neuron (the older SI in the authors' table the figures were made from, which is not included; see `SI_updated.ftr` below) |
| `npil` | Neuropil region |
| `pre_x`, `pre_y`, `pre_z` | Pre-synaptic site coordinates |
| `post_x`, `post_y`, `post_z` | Post-synaptic site coordinates |

### `neuron_data_full_article_princeton.ftr`

Generated by: `processing/05_build_neuron_metadata_table.py`

Per-neuron metadata table. Used by virtually all figure scripts. It is not a list of all neurons: a neuron whose axon/dendrite split failed gets no SI and is dropped (step 05, `dropna(subset='SI')`), and so is a neuron missing from the annotation file or with no synapse in the synapse table. A "% of neurons" taken from this table is a percentage of the neurons that remain.

| Column | Description |
|--------|-------------|
| `neuron` | Neuron root ID (int64); the column to join on |
| `root_id` | The same ID a second time (int64): step 05 merges the cells of the synapse table onto the annotated cells that have an SI, drops the rows that found no match, and then sets `root_id` from `neuron` (line 299), so the two are equal on every row |
| `super_class` | Neuron super-class (e.g., sensory, motor, central) |
| `primary_type` | Primary neuron type label |
| `nt_type` | Predicted neurotransmitter type from `neurons.csv` (the FlyWire prediction); the neurotransmitter figures use this column. Empty for about 14% of neurons |
| `nt_type_new` | The annotation file's `top_nt`, despite the name |
| `SI` | Segregation Index: 1 minus the synapse-weighted mean of the axon's and the dendrite's pre/post entropy, divided by the pre/post entropy of axon and dendrite pooled; linker synapses are not counted (`SI_calc` in `methods/methods_all.py`). In the authors' table the figures were made from (not included) this is the older SI; see `SI_updated.ftr` below |
| `cable_length` | Total skeleton cable length |
| `out_synapses_count` | Number of output (pre-synaptic) connections |
| `in_synapses_count` | Number of input (post-synaptic) connections |
| Morphological feature columns | Various per-neuron morphological measurements derived from SWC skeletons |
| Sensory rank columns | `allinputs_layer_mean` and per-modality sensory layer mean values |

### `connections_by_syn_type_reciprocal_types_filtered_article_princeton.ftr`

Generated by: `processing/06_build_connection_reciprocity_table.py`

Per-connection table. Used by Figures 3, 4, and 5.

| Column | Description |
|--------|-------------|
| `pre` | Pre-synaptic neuron root ID |
| `post` | Post-synaptic neuron root ID |
| `AA` | Number of axo-axonic synapses in this connection |
| `AD` | Number of axo-dendritic synapses |
| `DA` | Number of dendro-axonic synapses |
| `DD` | Number of dendro-dendritic synapses |
| `sum_syn` | Total synapse count in this connection |
| `reciprocal` | Whether a return connection (post -> pre) exists (int 0/1) |
| `primary_type_x`, `primary_type_y` | Primary type of the pre- and post-synaptic neuron |
| `same_type` | Whether pre and post neurons share the same primary type (int 0/1) |

### `neurons_pca_princeton.ftr`

Generated by: `processing/07_pca_morphology.py`

Per-neuron PCA scores from morphological features. Used by Figure 4 and one supporting script.

| Column | Description |
|--------|-------------|
| `neuron` | Neuron root ID |
| `PC1` | First principal component score (morphological gradient) |
| `PC2` | Second principal component score |

## Secondary derived tables (`data/derived/`)

These tables are produced as intermediate or auxiliary outputs.

| File | Generated by | Description |
|------|-------------|-------------|
| `SI_updated.ftr` | `05_build_neuron_metadata_table.py` | Per-neuron SI (`root_id`, `SI`), the same values step 05 then merges into the neuron table. Nine figure scripts always read SI from this file instead of from the neuron table (README lists them), and the revised Fig 4E and the Figure 6 script can be set to it. The authors' neuron table the figures were made from (not included) holds an older SI instead: on 54 rescored cells it equals the SI of the same split with self-synapses kept, while this file equals the SI without them (steps 01 and 02a drop them), which is what the manuscript's Methods describe. The two agree for the 182 largest cells, whose SI was computed without self-synapses in both |
| `swc_data.ftr` | Not generated by any script in this repository (the code in `05_build_neuron_metadata_table.py` that writes it is commented out) | Per-neuron SWC summary statistics; read by `05_build_neuron_metadata_table.py` |
| `reci_prop_princeton.ftr` | `figures/fig5/reciprocal_fraction.py` | Per-neuron reciprocal connection proportion |
| `full_reci_connections_article_filtered_princeton.ftr` | `06_build_connection_reciprocity_table.py` | Full list of reciprocal connection pairs. `Node A` is the smaller root ID of the pair and `Node B` the larger, so A and B do not mean pre and post; every A/B column follows that order |
| `reciprocity_list_full_article_princeton.ftr` | `06_build_connection_reciprocity_table.py` | Raw reciprocity edge list: one row per pair of neurons connected in both directions. `Node A` is the smaller root ID, and `Synapse Count` adds up the synapses in both directions |
| `connections_by_syn_type_filtered_article_princeton.ftr` | `06_build_connection_reciprocity_table.py` | One row per connection, indexed by (`pre`, `post`): synapse count for each synapse type (`comp`) and `sum_syn`; intermediate step of 06 |
| `connections_by_syn_type_reciprocal_filtered_article_princeton.ftr` | `06_build_connection_reciprocity_table.py` | The same table with `reciprocal` (int 0/1) added; intermediate step of 06 |
| `synapses_783_non_processed_princeton.ftr` | `03_merge_synapses_connectors.py` | Merged but unprocessed synapse table; read by `04_build_master_synapse_table.py` |
| `PC1_table.csv` | `figures/fig4/build_pc1_table.py` | One row per connection between intrinsic neurons: PC1, super-class, NT and SI of both neurons, and the AA/AD/DA/DD counts, `reciprocal` and `same_type`. `pre` and `post` are written as text and read back as integers. About 3 GB. Read by `figures/fig4/syntype_x_pc1.py` |
| `PC1_table_with_predictions.csv` | `figures/fig4/syntype_x_pc1.py` | PC1 table with model predictions appended |
| `synapses_783_article_princeton_raw.ftr`, `synapses_783_article_princeton_raw_with_self.ftr` | `processing/build_raw_synapse_table.py` | Synapse table before filtering, built from the Codex CSV as the authors' original split-method script does (row number as `synapse_id`, full root ids); the first without self-synapses (76,944,712 rows), the second with them (80,215,790). `RAW_TABLE_KEEP_SELF_SYNAPSES` in `config.py` chooses which one `SYNAPSE_TABLE_RAW_FTR` points to. Without self-synapses a split gives the SI of `SI_updated.ftr` and `SI_comparisons.ftr`; with them, the older SI of the authors' neuron table the figures were made from (not included). `tools/check_raw_synapse_table.py` checks both files. Has the columns `size` and `neuropil` that step 08 selects (so the step 04 table cannot stand in for it); read by `08_alternative_split_methods.py`, `09_maxsi_synapse_labels.py`, `figures/fig1/create_split_axon_dendrite_princeton.py` and the two `figures/split_methods/skeleton_comparisons*.py` scripts |
| `neuron_data_full_article.ftr`, `synapses_783_article.ftr`, `connections_by_syn_type_reciprocal_types_filtered_article.ftr` | Not generated by any script in this repository | Neuron, synapse and connection tables from the earlier, non-Princeton synapse detection; readers listed in `docs/data_availability.md` |
| `neurons_nt_bwf_frac.ftr` | `figures/fig7/fig7i_filopodia_fraction_x_nt.py` | Per-neuron table (`neuron`, `nt_type`, `filopodia_fraction`; every neuron of the bouton table with a neurotransmitter in `neuron_data.ftr`, from all super-classes); both readers use only its `filopodia_fraction` column (the fraction of a neuron's MSBs that carry a postsynaptic terminal, per the Supp 7-S4 legend; what "bwf" in the file name stands for is not settled). Read by `figures/fig5/reciprocal_fraction_x_bwf.py` and `figures/fig7/filopodia_x_mirror_neurons.py` |
| Fig 7 bouton tables: `b_table_full_prince(new)_filtered.ftr`, `bwf_table_full_prince(new)_filtered.ftr`, `filopodia_reciprocal.ftr`, `filopodia_filtered.ftr`, `inertia_all.ftr`, `neuron_data.ftr`, `t2.ftr` | Not generated by any script in this repository | Read by the `figures/fig7/fig7*.py` scripts (`neuron_data.ftr` also by `figures/fig4/syntype_x_pathway_layers.py`); columns in `docs/data_availability.md` (Fig 7 section) |
| `syn_bouton_filopodia.ftr` (in `data/raw/`) | Not generated by any script in this repository | Per-synapse filopodia flag (`synapse_id`, `filopodia_on_post`); read by the three `si_sim_*.py` scripts, merged on `synapse_id` |
| `syn_bouton_filopodia(new).ftr` (in `data/raw/`) | Not generated by any script in this repository | The same table with the flags set to 0 for cells outside the bouton table; read by `figures/fig7/post_on_filo_ratio.py` (Fig 7H), merged on `synapse_id` |
| `filopodia/nodes_baseline.ftr`, `filopodia/nodes_no_filopodia.ftr`, `filopodia/nodes_sampleout.ftr` | `figures/fig7/si_sim_baseline.py`, `si_sim_no_filopodia.py`, `si_sim_sampleout.py` | One row per neuron that has at least one AA/AD/DA/DD synapse (before any super-class filter): `neuron`, `<condition>_SI`, `axon_correct`, `dend_correct`, `axon_label`, `dend_label`, recomputed on the existing compartment labels after removing or subsampling incoming synapses only (outgoing synapses are always all counted). These are simulated values, not the published SI (random seeds fixed in the scripts). Read by `figures/fig7/si_comb_analysis.py` |
| `SI_comparisons.ftr` | `08_alternative_split_methods.py` | One row per intrinsic neuron: SI and phi for the published SFC split (`SFC_SI`, `SFC_Phi`), SI for the MaxSI cut (`MaxSI_SI`) and phi for the MinFisherP cut (`MinFisherP_Phi`) |
| `derived_maxsi/synapses_783_article_princeton.ftr` | `09_maxsi_synapse_labels.py` | The synapse table under the MaxSI split: the rows, columns and dtypes of `synapses_783_article_princeton.ftr`, with `comp` from the MaxSI labels (A or D at each end, no L) and `SI_pre`/`SI_post` the MaxSI SI of each end. A row with an end that has no label (its cell failed, the synapse sits on the cut node, or it was more than 10,000 nm from the skeleton) is left out. Only rows of `synapses_783_article_princeton.ftr` are kept: the MaxSI tables inherit the SFC table's cells and synapse rows, and a cell the SFC split failed on is never tried. `SYNAPSE_TABLE_FTR` points here when `SPLIT_METHOD = "maxsi"` in `config.py` |
| `derived_maxsi/neuron_data_full_article_princeton.ftr` | `09_maxsi_synapse_labels.py` | The neuron table under the MaxSI split: the columns of `neuron_data_full_article_princeton.ftr` and its rows, less the cells whose MaxSI labelling failed (dropped, as step 05 drops cells with no SI) and any cell left with no row in the MaxSI synapse table. `SI` is the MaxSI SI. `pre_A` to `post_L`, `axon_correct` and `dend_correct` describe the split, so they are recounted from the MaxSI synapse table with step 05's code. `linker` is 0 (the MaxSI split has no linker compartment). Every other column is the SFC table's, including the cell properties `out_synapses_count`, `in_synapses_count`, the degree and partner columns and the six ratio columns: these describe the cell, not the split; step 07's PCA and several figures use them. A cell can have an empty `axon_correct` or `dend_correct` here that the SFC table fills; step 09 prints how many, because the figures drop such cells. `NEURON_TABLE_FTR` points here when `SPLIT_METHOD = "maxsi"` |
| `derived_maxsi/SI_updated.ftr` | `09_maxsi_synapse_labels.py` | The format of `SI_updated.ftr` (`root_id` int64, `SI`), with `SI` the MaxSI SI of every cell step 09 labels. `SI_UPDATED_FTR` points here when `SPLIT_METHOD = "maxsi"` (config name `MAXSI_SI_UPDATED_FTR`) |
| The tables of steps 06 and 07 and of the figure scripts that write a table, in `derived_maxsi/` and `intermediate_maxsi/` under the published file names | The same scripts, run with `SPLIT_METHOD = "maxsi"` after step 09 | The published tables' columns, built on the MaxSI tables; their config names are listed in `MAXSI_SWITCHED`. Tables with no MaxSI version (`MAXSI_NOT_AVAILABLE`) are never written here; do not copy the SFC files in |

## Intermediate pipeline files (`data/intermediate/`)

All files here are generated by the pipeline and not committed.

| Location | Generated by | Description |
|----------|-------------|-------------|
| `processed_swc_data/` | `01_extract_compartments_SI.py` | One folder per skeleton subfolder, each with four PKLs covering all its neurons: `connectors.pkl`, `all_SI.pkl`, `issues.pkl`, `linker.pkl` (standard neurons) |
| `processed_big_neurons/` | `02a_large_neurons_pipeline.py` | Four PKLs per large neuron that splits: `connectors_<id>.pkl`, `all_SI_<id>.pkl`, `issues_<id>.pkl`, `linker_<id>.pkl`; a neuron that fails gets only `issues_<id>.pkl`, plus `non_success_connectors_<id>.pkl` when the split's compartments come out wrong |
| `connectors/pre_connectors_princeton.ftr` | `02b_merge_connectors.py` | Pre-synaptic connector table (standard neurons) |
| `connectors/post_connectors_princeton.ftr` | `02b_merge_connectors.py` | Post-synaptic connector table (standard neurons) |
| `connectors/pre_connectors_princeton_bign.ftr` | `02a_large_neurons_pipeline.py` | Pre-synaptic connector table (large neurons) |
| `connectors/post_connectors_princeton_bign.ftr` | `02a_large_neurons_pipeline.py` | Post-synaptic connector table (large neurons) |
| `connectors/synapses_pre_merge_princeton.ftr` | `03_merge_synapses_connectors.py` | Pre-merge synapse table |
| `alternative_to_SI/all_neurons_batches/` | `08_alternative_split_methods.py` | Per-batch split-method results: `summary_batch_NNNN.ftr` (one row per neuron), `nodes_batch_NNNN.ftr` (SI and Fisher test for every candidate node), `failures_batch_NNNN.ftr`, and `batch_run.json` (what the batches were made from, checked when a run reuses them) |
| `data/intermediate_maxsi/maxsi_labels/batches/` | `09_maxsi_synapse_labels.py` | Per-batch MaxSI labels: `labels_batch_NNNN.ftr` (`synapse_id`, `neuron`, `side` pre/post, `label` A/D; one row per labelled synapse end), `summary_batch_NNNN.ftr` (one row per cell: `best_node_id`, `MaxSI_SI`, `n_tied_max_SI` and `n_tied_max_SI_distinct_sides` (nodes sharing the highest SI, and how many different side counts they give), `n_close_max_SI` (nodes within numpy isclose of it, for information), side counts, `axon_side`), `failures_batch_NNNN.ftr` (`neuron`, `error`) and `batch_run.json` (what the batches were made from, including the number of skeleton files, a hash of their paths and sizes and the navis version). Each batch file is written under a temporary name and renamed, the failures file last |
| `data/intermediate_maxsi/maxsi_labels/subset/` | `09_maxsi_synapse_labels.py` with `ONLY_LOCAL_SKELETONS` or `LIMIT` | The same batches and the three MaxSI tables for the cells whose skeletons are local; for checking only. The synapse table keeps only rows whose two ends are both cells of the run, so the subset neuron table's `pre_A` to `post_L` are not the full cells' counts |
| `reciprocity/models/final_random_forest_model_princeton.pkl` | `figures/fig5/reciprocal_fraction_model.py` | Saved random forest model for reciprocity prediction |
