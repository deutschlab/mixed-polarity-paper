# Generated Tables

The tables the pipeline makes: which script writes each one, and its columns. None is committed. Most come from
`processing/01_*.py` to `07_*.py`, run in order; the rows marked "Not generated by any script" come from the authors.

The folders here are those of `PIPELINE_RUN = "published"` (`data/derived/`, the authors' delivered tables). A fresh
run (`PIPELINE_RUN = "rebuild"`) writes the same files to `data/derived_rebuild/` and `data/intermediate_rebuild/`,
and step 09 with `SPLIT_METHOD = "maxsi"` to `data/derived_rebuild_maxsi/`; the main figures use that last folder.

**Two SIs under one name.** In `data/derived/`, the neuron table's `SI` and the synapse table's `SI_pre`/`SI_post`
are an older SI computed with synapses from a cell to itself kept; `SI_updated.ftr` there leaves them out, as the
Methods do, and the two differ for 137,937 of the neuron table's 138,289 cells. A fresh run leaves them out
everywhere, so in `data/derived_rebuild/` the neuron table's `SI` equals `SI_updated.ftr` for every cell.

See [pipeline_overview.md](pipeline_overview.md) for the run order and each script's inputs and outputs, and
[data_availability.md](data_availability.md) for the raw inputs.

## Main tables

### `synapses_783_article_princeton.ftr`

Written by `processing/04_build_master_synapse_table.py`. One row per synapse between two cells that both have an SI,
with a neuropil and both ends attached to a skeleton. Almost every figure script reads it.

| Column | Description |
|--------|-------------|
| `synapse_id` | Row number of the synapse in the Codex CSV, not a Codex ID; it matches only that exact file |
| `pre` | Presynaptic cell ID (int64) |
| `post` | Postsynaptic cell ID (int64) |
| `comp` | The presynaptic end's compartment, then the postsynaptic end's (`A` axon, `D` dendrite, `L` linker). On the SFC split nine values are possible: `AA` (axo-axonic), `AD` (axo-dendritic), `DA` (dendro-axonic), `DD` (dendro-dendritic), and five with a linker end (`AL`, `LA`, `DL`, `LD`, `LL`). Filter to `AA`/`AD`/`DA`/`DD` before analysing synapse types. On the MaxSI split only those four occur |
| `SI_pre`, `SI_post` | SI of the presynaptic and the postsynaptic cell (in `data/derived/`, the older SI; see above) |
| `npil` | Neuropil |
| `pre_x`, `pre_y`, `pre_z` | Presynaptic site |
| `post_x`, `post_y`, `post_z` | Postsynaptic site |

On the SFC split a linker is the stretch of skeleton between axon and dendrite that neither side takes in; most split
cells have one, and its length is not limited. On the MaxSI split there is no linker: the cell is cut at one node, and
the synapses on that node get no label, so they are not in the table.

### `neuron_data_full_article_princeton.ftr`

Written by `processing/05_build_neuron_metadata_table.py`. One row per cell that has an SI, is in the annotation
file and has a synapse in the synapse table. So it is not a list of all neurons: a cell whose split failed has no SI
and is dropped (`05:129`), and a "% of neurons" taken from it is a share of the cells left.

| Column | Description |
|--------|-------------|
| `neuron` | Cell ID (int64); the column to join on |
| `root_id` | The same ID again (int64). Step 05 merges the synapse table's cells onto the annotated cells with an SI, drops the rows with no match, and sets `root_id` from `neuron` (`05:239`), so the two are equal on every row |
| `super_class` | Super-class (for example sensory, motor, central) |
| `primary_type` | Primary cell type |
| `nt_type` | Predicted neurotransmitter from `neurons.csv` (the FlyWire prediction); the neurotransmitter figures use this column. Empty for about 14% of cells |
| `nt_type_new` | The annotation file's `top_nt`, despite the name |
| `SI` | Segregation index: 1 minus the synapse-weighted mean of the axon's and the dendrite's pre/post entropy, divided by the pre/post entropy of axon and dendrite pooled; linker synapses are not counted (`SI_calc` in `methods/methods_all.py`). In `data/derived/`, the older SI (see above) |
| `pre_A`, `pre_D`, `pre_L`, `post_A`, `post_D`, `post_L` | The cell's presynaptic and postsynaptic ends in each compartment, counted from `comp` in the synapse table (int64; `05:167-192`) |
| `axon_correct`, `dend_correct` | Share of the axon's ends that are presynaptic, `pre_A / (pre_A + post_A)`, and of the dendrite's that are postsynaptic, `post_D / (pre_D + post_D)` (`05:195-197`). Most figures drop cells where either is empty |
| `out_synapses_count`, `in_synapses_count` | The cell's synapses in the synapse table as presynaptic and as postsynaptic cell, all nine `comp` values included (float64) |
| `out_partners`, `in_partners`, `max_out_degree`, `max_in_degree`, `mean_out_degree`, `mean_in_degree` | Partner counts and synapses per partner |
| Six ratio columns | Ratios of the synapse and partner counts (`05:231-236`) |
| `nodes`, `leafs`, `branches`, `cable_length` | From `swc_data.ftr`: skeleton nodes, end nodes, branch nodes (float64 here, after a left merge), and cable length in nm (float32) |
| `length_nm`, `area_nm`, `size_nm` | From `cell_stats.csv` |
| `linker` | Do not use: step 05 fills it by row position (`05:69`) and loses the large cells' flags (`05:87-88`), so it does not say which cells have a linker |
| Sensory rank columns | `<modality>_layer_mean` for 13 modalities (`allinputs`, `allsensory_novisual`, `ascending`, `gustatory`, `hygrosensory`, `mechanosensory`, `auditory`, `jo`, `peg`, `ocellar`, `olfactory`, `thermosensory`, `visual_projection`), each matched on its file's own `root_id`; NaN for a cell not in that file. The eye- and head-bristle files are not kept. In the published table (`data/derived/`) only `allinputs_layer_mean` is matched by cell ID; the other columns hold other cells' values |

### `connections_by_syn_type_reciprocal_types_filtered_article_princeton.ftr`

Written by `processing/06_build_connection_reciprocity_table.py`. One row per (`pre`, `post`) pair with at least one
AA, AD, DA or DD synapse. Linker synapses are not counted. Used by Figures 3, 4
and 5.

| Column | Description |
|--------|-------------|
| `pre`, `post` | Presynaptic and postsynaptic cell ID |
| `AA`, `AD`, `DA`, `DD` | Synapses of each type in this connection (float64, 0 where none) |
| `sum_syn` | AA + AD + DA + DD |
| `reciprocal` | 1 if the pair is also connected the other way (post to pre) by at least one AA, AD, DA or DD synapse, else 0 (int) |
| `primary_type_x`, `primary_type_y` | Primary type of the presynaptic and the postsynaptic cell; empty for a cell not in the neuron table |
| `same_type` | 1 if both cells have the same primary type, else 0 (int); 0 when either type is empty |

### `neurons_pca_princeton.ftr`

Written by `processing/07_pca_morphology.py`. One row per cell of the four analysed super-classes (`central`,
`optic`, `visual_projection`, `visual_centrifugal`) with none of the eight PCA inputs missing. The inputs are
standardised first: `length_nm`, `area_nm`, `size_nm` (from `cell_stats.csv`), `leafs` (from `swc_data.ftr`), and the
input and output synapse and partner counts. The sign of PC1 is arbitrary. Read by `figures/fig2/si_x_pca.py`, five
Fig 4 scripts, `figures/supporting/pc1_x_nt_sclass_pies.py` and `tools/check_simple_pc1_model.py`.

| Column | Description |
|--------|-------------|
| `neuron` | Cell ID |
| `PC1` | First principal component |
| `PC2` | Second principal component |

## Tables on the MaxSI, MinFisherP and MaxPhi splits

Written by step 09 and the scripts after it. Under `PIPELINE_RUN = "published"` they go to `derived_maxsi/` (and
`_minfisherp`, `_maxphi`); under `"rebuild"` to `derived_rebuild_maxsi/` and so on. With `SPLIT_METHOD` set to a
method, `SYNAPSE_TABLE_FTR`, `NEURON_TABLE_FTR` and `SI_UPDATED_FTR` point to that method's tables.

| File | Written by | Description |
|------|-------------|-------------|
| `synapses_783_article_princeton.ftr` | `09_maxsi_synapse_labels.py` | The synapse table on the MaxSI split: the rows, columns and dtypes of the SFC table, with `comp` from the MaxSI labels (A or D at each end, no L) and `SI_pre`/`SI_post` the MaxSI SI of each end. A row with an end that has no label is left out: its cell failed, the synapse sits on the cut node, or it was more than 10,000 nm from the skeleton. Every row comes from the SFC table, and a cell the SFC split failed on is never tried |
| `neuron_data_full_article_princeton.ftr` | `09_maxsi_synapse_labels.py` | The neuron table on the MaxSI split: the SFC table's columns and rows, without the cells whose MaxSI labelling failed (dropped, as step 05 drops cells with no SI) and any cell left with no row in the MaxSI synapse table. `SI` is the MaxSI SI. `pre_A` to `post_L`, `axon_correct` and `dend_correct` describe the split, so they are recounted from the MaxSI synapse table with step 05's code; `pre_L`, `post_L` and `linker` are 0. Every other column is the SFC table's, including `out_synapses_count`, `in_synapses_count`, the degree and partner columns and the six ratio columns: they describe the cell, not the split, and step 07's PCA and several figures use them.
