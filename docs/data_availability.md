# Data Availability

This document describes all input data files required to reproduce the analyses in the manuscript,
where each file comes from, and where to place it in the repository.

Two inputs are included in this repository under `data/raw/`: the neuron annotation table
(`Supplemental_file1_neuron_annotations.csv`) and the 15 sensory-rank files in `ranks/`.
All other raw data must be downloaded separately (see below). All derived tables
are generated by running the processing pipeline (see [pipeline_overview.md](pipeline_overview.md)).

---

## Public FlyWire / Codex inputs

The following files are available from the FlyWire Codex download page:

> https://codex.flywire.ai/api/download?dataset=fafb

Codex offers several datasets on that page; this project uses FAFB v783 only. Files from another
dataset can have the same column names and load without an error, so check the dataset before you
download. At the time of writing the site asks you to sign in with a Google account and accept the
FlyWire terms of service before downloading.

Download the `.csv.gz` files, decompress them, and place them at the paths shown below
(relative to the repository root). Update `config.py` if any filename differs from what is listed.

| File | Local path | Config variable | Description |
|------|-----------|----------------|-------------|
| Princeton synapse detection table | `data/raw/fafb_v783_princeton_synapse_table.csv` | `PRINCETON_SYNAPSE_CSV` | Complete synapse table for FAFB v783. Columns used: `pre_root_id_720575940`, `post_root_id_720575940`, `pre_x/y/z`, `post_x/y/z`, `size`, `neuropil`. After downloading and decompressing, rename the file to match the config variable or update `PRINCETON_SYNAPSE_CSV` in `config.py`. |
| Neurotransmitter-type predictions | `data/raw/neurons.csv` | `NEURONS_CSV` | Per-neuron neurotransmitter predictions. Columns used: `root_id`, `nt_type`. Download `neurons.csv.gz` from the Neurotransmitter Type Predictions section. |
| Cell size statistics | `data/raw/cell_stats.csv` | `CELL_STATS_CSV` | Per-neuron cell size measurements. Expected columns: `root_id`, `length_nm`, `area_nm`, `size_nm`. Download `cell_stats.csv.gz` from the Cell Size Measurements section. |
| Neuron classification hierarchy | `data/raw/classification.csv` | `CLASSIFICATION_CSV` | Per-neuron classification labels. Expected columns: `root_id`, `flow`, `super_class`, `class`, `sub_class`, `hemilineage`, `side`, `nerve`. Download `classification.csv.gz` from the Classification section. Used by `figures/fig3/syntype_x_identity.py` and `figures/fig5/syn_type_x_reci_x_dominance_x_sides.py`. |
| SWC morphology skeletons | `data/raw/swc/783/` | `SWC_DIR` | One SWC skeleton file per neuron. Download `sk_lod1_783_healed.zip` from the Neuron Skeletons section; extract the archive and place the SWC files in `data/raw/swc/783/`. Steps 01, 02a and 08 look for skeletons only in subfolders of `SWC_DIR` (one subfolder per batch, for example about 1,500 neurons each), with each file named `<root_id>.swc`; files placed directly in `SWC_DIR` are not found, and step 01 then finishes without output or error. |



## Bundled in this repository

The following small files from Dorkenwald et al. 2024 are included directly in this repository
under `data/raw/` and do not need to be downloaded separately.

| File | Local path | Config variable | Description |
|------|-----------|----------------|-------------|
| `Supplemental_file1_neuron_annotations.csv` | `data/raw/Supplemental_file1_neuron_annotations.csv` | `NEURON_ANNOTATIONS_CSV` | Combined neuron annotation table. Columns: `root_id`, `super_class`, `top_nt`, `cell_type`. Supplementary annotation file from Dorkenwald et al. 2024 (see citation below). Required by `processing/05_build_neuron_metadata_table.py`, `figures/fig2/si_x_primary_types_mirror.py`, and `figures/fig3/si_x_neuron_types.py`. |
| Sensory layer rank feather files | `data/raw/ranks/` | `RANKS_DIR` | Per-neuron sensory layer rank feather files. Columns include `root_id`, `allinputs_layer_mean`, and per-modality layer means (visual, olfactory, mechanosensory, etc.). From Dorkenwald et al. 2024 (see citation below). Required by `processing/05_build_neuron_metadata_table.py`. |

## Author-provided manuscript inputs

The following file is not available from public databases and must be obtained from the
corresponding authors.

| File | Local path | Config variable | Description |
|------|-----------|----------------|-------------|
| Neuropil synapse table | `data/raw/Cloud_SQL_fw_mat783_synapses_v3_neuropil.csv` | `NEUROPIL_SYNAPSE_CSV` | Synapse table with neuropil annotations, derived from FlyWire data published in Dorkenwald et al. 2024 (see citation below). Required only by `figures/fig2/si_x_twigs.py` (Fig 2 supplementary panel). |


> Dorkenwald S, Matsliah A, Sterling AR, Schlegel P, Yu SC, McKellar CE, et al. Neuronal wiring diagram of an adult brain. *Nature* 634(8032), 124–138 (2024). https://doi.org/10.1038/s41586-024-07558-y

The FlyWire annotations also ask users to cite:

> Schlegel P, Yin Y, Bates AS, Dorkenwald S, Eichler K, Brooks P, et al. Whole-brain annotation and multi-connectome cell typing of *Drosophila*. *Nature* 634(8032), 139–152 (2024). https://doi.org/10.1038/s41586-024-07686-5

> Matsliah A, Yu SC, Kruk K, Bland D, Burke AT, Gager J, et al. Neuronal parts list and wiring diagram for a visual system. *Nature* 634(8032), 166–180 (2024). https://doi.org/10.1038/s41586-024-07981-1

The larval `.ftr` output files are generated by running `processing/larva/larva_process.py`. As committed, that script produces no usable output (see `docs/pipeline_overview.md`).
That script requires three raw input files from the larval connectome published in:

> Winding M, Pedigo BD, Barnes CL, et al. The connectome of an insect brain.
> *Science* 379(6636), eadd9330 (2023). https://doi.org/10.1126/science.add9330

Place these files under `data/larva/raw/` before running `larva_process.py`:

| File | Local path | Config variable | Description |
|------|-----------|----------------|-------------|
| Larval synapse table | `data/larva/raw/synapse_table.csv` | `LARVA_SYNAPSE_TABLE_CSV` | Raw synapse table from the larval connectome. Columns (assigned by script): `rowid`, `pre_skeleton_node_id`, `connector_id`, `pre_x/y/z`, `connector_x/y/z`, `post_skeleton_node_id`, `post_x/y/z`, `pre`, `post`. |
| Neuron filter list | `data/larva/raw/n_list3.csv` | `LARVA_NEURON_LIST_CSV` | CSV listing the larval neuron IDs to include. Column: `neuron`. |
| SWC skeleton files | `data/larva/raw/swc/all_neurons/` | `LARVA_SWC_DIR` | One SWC skeleton file per larval neuron (fixed format with metadata header). |

Seven inputs are read by the code but not written by any script in this repository:

- `synapses_783_article_princeton_raw.ftr`, read by `08_alternative_split_methods.py` and `figures/fig1/create_split_axon_dendrite_princeton.py`
- `neurons_nt_bwf_frac.ftr`, read by `figures/fig5/reciprocal_fraction_x_bwf.py`
- `swc_data.ftr`, read by `05_build_neuron_metadata_table.py` (the only code that writes it is commented out)
- three tables from the earlier, non-Princeton synapse detection: `neuron_data_full_article.ftr` (read by `figures/fig2/si_comparisons.py`, `figures/fig3/si_x_correct_percent_per_compartment_buhmann.py` and `figures/fig5/fig5d_chi_reci_identity.py`), `synapses_783_article.ftr` (read by `figures/fig2/si_comparisons.py`, `figures/fig3/si_x_correct_percent_per_compartment_buhmann.py` and `figures/fig3/si_x_npil_x_synapse_detection.py`) and `connections_by_syn_type_reciprocal_types_filtered_article.ftr` (read by `figures/fig5/fig5d_chi_reci_identity.py`)
- `neurons_pca.ftr`, read by `figures/fig4/syntype_x_pc1_simple_model.py`, which merges it onto the Princeton neuron table

None of these seven files is deposited with this repository. Those scripts cannot run until the files are supplied. Because step 05 needs `swc_data.ftr`, the neuron table, and every step and figure that reads it, cannot be rebuilt from the downloads alone.
